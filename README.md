How to use:
1. Account banao ya login karo (email/password ya Google).
2. Month chuno aur monthly budget daalo.
3. Items add karo: quantity, price, category, priority.
4. Meter yellow (80%+) aur red (over budget) hota hai.
5. Neeche "All budgets" me har mahine ka budget, status aur full item list dikhti hai.
6. Data cloud me save hota hai, kisi bhi device se same login se dikhta hai.
